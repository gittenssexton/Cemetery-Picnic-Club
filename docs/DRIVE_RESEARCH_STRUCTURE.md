## How to use this
- Each cemetery gets a fieldwork/research folder like Pine Grove, but NOT its own independent scholarly motif and maker databases.
- Each research claim must cite a stable source record with bibliographic metadata and pages/figures.
- Store copyrighted files only with a lawful acquisition and usage basis. Citation alone is not permission to redistribute.
- A stone's symbolism may have different interpretations by date, location, tradition and scholar: keep multiple sourced interpretations.
- Store originals separately from derived crop/AI annotation; track rights and processing permissions.
- GitHub retains code and migrations; Drive stores research and administrative evidence; Cloudflare D1/R2 will eventually hold live structured records and permitted image objects.
